# 新标签页 · New Tab

一个新标签页：**一个搜索框 + 可切换搜索引擎 + 自定义壁纸与 Logo**。
无广告、无追踪、不联网上传，所有设置只存在本机浏览器里。

- 🌐 7 个搜索引擎随时切换（Google / Bing / 百度 / DuckDuckGo / 搜狗 / 360搜索 / Yandex）
- 🖼️ 本地图片一键设为壁纸
- 🎨 本地图片一键替换页面 Logo
- ⌨️ 按 `/` 快速聚焦搜索框，输入网址直达
- 🔒 零权限、零网络请求、零数据收集（仅需 `storage` 级别的本地保存）
- 📦 纯静态三件套，无需构建工具

## 在线使用

访问：<https://blupureqingan.github.io/ntp-extension/>

把它设为浏览器主页或新标签页即可。

## 作为 Chrome 扩展安装

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库目录
4. 打开一个新标签页即可看到效果

发布版在 Chrome 应用商店上架后，可直接搜索安装（Manifest V3）。

## 目录结构

```
ntp-extension/
├─ index.html      页面结构 + 全部样式
├─ engines.js      搜索引擎图标生成（SVG 描摹 + 光学居中）
├─ ntp.js          交互逻辑（搜索、切换引擎、壁纸、Logo）
├─ manifest.json   扩展清单（Manifest V3）
└─ icons/          16 / 48 / 128 图标
```

## 技术说明

图标全部是内联 SVG，不依赖任何外部资源：

- 必应、谷歌使用官方 logo，其中必应图标由 500×500 位图**矢量描摹**而来
  （轮廓追踪 + Kåsa 圆拟合 + Douglas-Peucker 简化，与原图 IoU = 0.969）。
- 文字类图标采用**光学居中**：按墨迹重心而非外框居中，
  保证 D、Я、搜 这类笔画分布不均的字形视觉上也是正的。

## 隐私

不收集、不上传任何数据。壁纸、Logo、搜索引擎选择均保存在浏览器本地存储中，
卸载扩展或清除站点数据即可完全删除。
